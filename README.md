# 🎓 Adyapana Higher Education Institute Management System

A comprehensive desktop-based Institute Management System built using **Java Swing**, **MySQL**, and **JasperReports**. Designed to streamline daily administrative operations at Adyapana Higher Education Institute, it handles student and teacher registrations, class scheduling, attendance tracking, and fee payments with printable invoices.

## ✨ Key Features

* **Authentication & User Management:**
  * Animated Splash Screen and secure Admin Login.
  * User registration with role management (Admin / Super Admin), active/inactive status toggling, search, and delete options.
* **Student & Teacher Management:**
  * Complete CRUD (Create, Read, Update, Delete) operations and real-time search for both Students and Teachers.
  * Mobile number validation and dynamic city/gender dropdowns.
* **Academic Scheduling:**
  * Subject registration with course descriptions and fee pricing.
  * Class registration with dedicated time slots.
  * Assign specific subjects and classes to teachers.
* **Attendance & Billing:**
  * Mark and track daily student attendance by class.
  * Record student payments by subject and payment type, check payment history, and generate printable **JasperReports Invoices**.

## 🛠️ Tech Stack
* **Language:** Java (Core)
* **GUI Framework:** Java Swing (`javax.swing`)
* **Database:** MySQL (`adyapana_db`)
* **Reporting:** JasperReports (`Invoice.jrxml`)
* **IDE:** NetBeans
